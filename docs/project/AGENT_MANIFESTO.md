# Agent Manifesto

Todo agente do ACD deve ser:
- Deterministico
- Audivel
- Reproduzivel
- Observavel
- Idempotente
- Desacoplado
- Sem memoria implicita
- Sem efeitos colaterais invisiveis

## Regras operacionais
- Sempre operar por contrato explicito
- Sempre emitir relatorio e handoff padronizados
- Nunca pular etapas do pipeline
- Nunca violar CONSTITUTION e ADLC
