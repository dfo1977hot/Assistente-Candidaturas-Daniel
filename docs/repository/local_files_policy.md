# Local Files Policy

| Class | Version control policy |
|---|---|
| Code, tests, reviewed documentation, constraints, official scripts, QSS | Versionable after review |
| Example configuration | Versionable; use `.env.example`, never `.env` |
| Coverage and architecture baselines in `quality/` | Versionable; only official mechanisms may promote coverage |
| SQLite databases, WAL/SHM, backups, dumps, fixtures generated by tests | Exclusively local unless an explicitly reviewed fixture is added |
| Personal data, candidate documents, attachments, screenshots | Local and retention-reviewed; never package or reproduce in diagnostics |
| Credentials and `.env` | Exclusively local and secret |
| Caches, basetemps, virtualenvs, builds, wheels, sdists | Exclusively local and reproducible |
| Raw Gate output, logs, PIDs, wrappers, diagnostics | Exclusively local; version only summary manifests |

Raw evidence belongs under `.local/artifacts/` after a separate hash-verified
migration. Record origin, size, timestamp, and SHA-256 before and after every
move. `DatabaseBootstrap` reconstructs a new local database from the explicit
92-table Registry. Never commit or package a real database.
