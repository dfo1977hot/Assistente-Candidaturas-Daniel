# RFC-0003 - Pipeline Sequencial de Agentes

## Status
Accepted

## Contexto
Execucao paralela sem handoff formal elevava risco de inconsistencias.

## Proposta
Pipeline obrigatorio: Architecture -> Implementation -> Refactoring -> Testing -> Documentation -> Release.

## Decisao
Aprovado com bloqueio automatico quando etapa anterior reprovar.

## Impacto
Aumenta controle de qualidade e reduz risco de release com lacunas.
