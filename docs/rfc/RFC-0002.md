# RFC-0002 - Architecture Inventory como Gate

## Status
Accepted

## Contexto
Faltava bloqueio formal para impedir sprints em arquitetura degradada.

## Proposta
Tornar Architecture Inventory obrigatoria antes de qualquer sprint.

## Decisao
Aprovado com status APPROVED ou BLOCKED e Architecture Score.

## Impacto
Previne retrabalho e reintroducao de duplicacoes estruturais.
