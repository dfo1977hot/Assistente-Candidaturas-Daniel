# Architecture Decision Records (ADR)

Este diretório registra todas as decisões arquiteturais relevantes do Assistente de Candidaturas do Daniel (ACD).

Cada ADR descreve:

- Contexto
- Problema
- Alternativas consideradas
- Decisão tomada
- Consequências

Os ADRs são permanentes e nunca devem ser apagados.

Caso uma decisão seja alterada, um novo ADR deve ser criado substituindo o anterior.

Exemplo:

ADR-001
↓

ADR-008 substitui ADR-001

mantendo todo o histórico.
