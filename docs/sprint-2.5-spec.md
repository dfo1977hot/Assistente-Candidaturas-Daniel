# Sprint 2.5 — Módulo de Gestão Inteligente de Currículos

## Objetivo

Implementar o gerenciamento de currículos com múltiplas versões, importação de documentos, associação a candidaturas e indicadores básicos no dashboard.

## Funcionalidades

- Cadastro de currículos
- Importação de arquivos DOCX/PDF
- Versionamento incremental
- Ativação de currículo padrão
- Associação a candidaturas
- Histórico de versões
- KPIs de uso no dashboard

## Arquitetura

- Clean Architecture
- Repository Pattern
- Service Layer
- SQLAlchemy ORM
- SQLite
- PySide6
