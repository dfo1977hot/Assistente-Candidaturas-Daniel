# Quick Start

1. Start the desktop app.
2. Open the dashboard.
3. Create a company.
4. Create a vacancy for that company.
5. Create a curriculum.
6. Create an application.
7. Add an interview and notes.
8. Refresh the dashboard.
9. Create a backup.
10. Reopen the app and confirm the data is still there.

## Notes

- The official route is `ApplicationPage`.
- Contact management is not a first-class MVP surface in the current product.
