# Candidate Decision UI Validation Checklist

- [ ] Start the desktop application.
- [ ] Open Candidaturas with no selection.
- [ ] Select a valid candidatura.
- [ ] Switch between two candidaturas.
- [ ] Verify `INSUFFICIENT_DATA`.
- [ ] Verify long decision content and vertical scrolling.
- [ ] Resize and maximize the window.
